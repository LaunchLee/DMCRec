# Supplementary material S1: corrected evaluation results

This archive accompanies the DMCRec manuscript. It contains derived aggregate research data, not individual participant records or trained checkpoints. Run `python verify_results.py` to recompute all means and sample standard deviations from `runs.json`. `per_seed_metrics.csv` is the same data in long format. `summary.json` preserves full precision; manuscript tables round these values.

There are 115 final model evaluations in 23 groups, with seeds 42–46. Multiple scoring modes on one trained model are not additional training runs. All seeds use the fixed split seed 42. Data are randomly divided into training/validation/test fractions 0.7/0.1/0.2; source x_label values are not used as split assignments. All observed ratings are binary interactions. Unknown entities are excluded from evaluation. See `data_protocol.json` for catalog counts, held-out counts and input fingerprints.

DMCRec, WMF and MENTOR use two-candidate validation-only training grids at seed 42 and 200 epochs. DMCRec searches contrastive weight 0.005/0.01 (Baby selects 0.005, Sports 0.01); WMF and MENTOR search learning rates 0.0001/0.001 (selected 0.001 and 0.0001). Controls inherit the selected full-model configuration. The MF pair searches learning rate 0.0001/0.001; MACR-MF additionally selects the reference on validation from [0, 0.5, 1, 2, 5, 10, 20, 22, ..., 40]. Four selected seed42 fits are reused as final fits. Reference selection is shared across final seeds. The original MACR study used a different training/evaluation protocol; this is an explicitly adapted comparison.

The main DMCRec score fixes modulation; factual is the joint matching/modulation score; counterfactual is the reference contrast. Baby includes the fixed-model DMCRec scoring comparison. MACR-MF uses its counterfactual score as primary, MF-BCE uses main. Lower ARP and recommendation Gini describe recommendation distribution and are not universal quality objectives. Training-seed variability on one split does not measure population uncertainty. The study reports model-level interventions on a fitted scorer.

Original inputs: public Amazon Baby and Sports data/features distributed through the MMRec project (https://github.com/enoche/MMRec), originating in the Amazon product dataset described in the manuscript. Source-provider terms apply; third-party raw data and features are not redistributed here. Place each dataset under experiments/dmcrec/datasets/MMRec-Baby or MMRec-Sports with image_feat.npy, text_feat.npy, baby.inter or sports.inter, and the supplied i_id_mapping.csv/u_id_mapping.csv. Float32 image conversion preserves feature values subject to floating-point rounding. Input fingerprints document the precise processed inputs used in the reported study.

This anonymous archive contains no author or institution identifiers, SSH addresses, access tokens, local absolute paths, or user-level histories. Its scripts verify derived summaries; rerunning model training requires the separately supplied reproducibility code and source data.
